# CDL → Census QuickStats Dictionary

## Overview

This document maps CDL crop codes to their QuickStats commodity names for the
Census of Agriculture 2012. It is the authoritative reference for
`3_Availability_Census.R`.

The mapping is used to compute `Δ_acres = CDL_acres - Census_acres` per category
(GM / Tolerant / Vulnerable) as part of the bias correction score:

$$S_i = w_1 \cdot |\Delta_{\text{acres}}| + w_2 \cdot U$$

## Source files

| File | Role |
|------|------|
| `data/metadata/CDL_CENSUS_MAP.xlsx` | CDL code => Census commodity; maintained manually |
| `data/metadata/census_shortdesc_map.csv` | Census commodity => exact `short_desc` strings; generated by `3_Availability_Census.R` |
| `data/CENSUS/census_area_2012.csv` | Final filtered area dataset; output of `3_Availability_Census.R` |
| 'data/metadata/missing_geoid_census.csv`| GEOIDS missing in our Census Area Measurement; generated by `3_Availability_Census.R` |

**For the exact `short_desc` string used per commodity, refer to
`census_shortdesc_map.csv` directly.** It is regenerated automatically when
`3_Availability_Census.R` is re-run, so it is always up to date. For the missing GEOIDs, the reason is also given in the CSV file.

## General rules

- **Statistic**: use `AREA HARVESTED` for field crops and vegetables. Use
  `AREA BEARING & NON-BEARING` for permanent orchards (tree fruits, nuts, vines).
  Use `AREA IN PRODUCTION` for CUT CHRISTMAS TREES (only available statcat).
- **No irrigated subsets**: rows containing `IRRIGATED` in `short_desc` are
  excluded as they are subsets of their parent.
- **No operations rows**: only rows ending in `ACRES HARVESTED`,
  `ACRES BEARING & NON-BEARING`, or `ACRES IN PRODUCTION` are kept.
- **Aggregation**: for commodities with no top-level `short_desc`, the
  non-irrigated subcategory rows are summed. Subcategories partition the total
  by type (e.g. GRAIN vs SILAGE) or marketing channel (FRESH MARKET vs
  PROCESSING) without overlap. See aggregation decisions below.

## Special cases and substitutions

**SMALL GRAINS (CDL 25):** `SMALL GRAINS` exists in Census but no county code available. We cannot use it. So we map CDL 25 to `WHEAT` instead.

**GOURDS (CDL 249):** no county-level Census counterpart. Mapped to `SQUASH`
as the closest botanical equivalent.

**CUT CHRISTMAS TREES (CDL 70):** no `ACRES HARVESTED` row available.
`ACRES IN PRODUCTION` is used instead. Because the other measure available is `ACRES HARVESTED, measured in trees` and it corresponds less to CDL. 

**WALNUTS:** only `WALNUTS, ENGLISH` is available in QuickStats at county level.

**TOMATOES:** `TOMATOES, IN THE OPEN` is used. It is the aggregate of
fresh market + processing subtypes, so no summing needed.

**MELONS:** CDL codes 48 (Watermelons), 209 (Cantaloupes), and 213 (Honeydew)
all map to the single Census commodity `MELONS`. The three subtypes
(CANTALOUP, HONEYDEW, WATERMELON) are summed.

**HAY (CDL 36, 37, 58, 224):** CDL 36 (Alfalfa), 37 (Other Hay), 58
(Clover/Wildflowers), and 224 (Vetch) all map to `HAY - ACRES HARVESTED`.
Census total HAY covers all subtypes.

**PLUMS & PRUNES:** CDL 220 (Plums) maps to `PLUMS & PRUNES` in Census, which
already aggregates both. CDL 210 (Prunes) maps separately to `PRUNES`. Be
careful not to double-count when aggregating at category level.

## CDL codes with no Census counterpart

Excluded from validation. Pixels are counted in CDL acres but not in CENSUS => upward bias for those categories:

| CDL Code | CDL Name | Reason |
|----------|----------|--------|
| 44 | Other Crops | Too broad |
| 47 | Misc Vegs & Fruits | Too broad |
| 71 | Other Tree Crops | No Census counterpart |

## Aggregation decisions for complex commodities

These commodities have no top-level `<COMMODITY> - ACRES HARVESTED` row in
QuickStats at county level. The subtypes below are non-overlapping and
exhaustive. See `3_Availability_Census.R` for the full exploration code.

| Commodity | Subtypes summed |
|-----------|----------------|
| BEANS | SNAP + GREEN LIMA + DRY EDIBLE (EXCL LIMA) + DRY EDIBLE LIMA |
| BLUEBERRIES | TAME + WILD |
| CABBAGE | HEAD + CHINESE + MUSTARD |
| CHERRIES | TART + SWEET |
| CORN | GRAIN + SILAGE |
| CUT CHRISTMAS TREES | IN PRODUCTION (only available statcat) |
| GREENS | TURNIP + COLLARD + MUSTARD + KALE |
| HERBS | FRESH CUT + DRY |
| MELONS | CANTALOUP + HONEYDEW + WATERMELON |
| MILLET | PROSO (only subtype available) |
| MINT | OIL + TEA LEAVES |
| MUSTARD | SEED (only subtype available) |
| ONIONS | DRY + GREEN |
| PEAS | GREEN (EXCL SOUTHERN) + GREEN SOUTHERN (COWPEAS) + DRY SOUTHERN (COWPEAS) + CHINESE (SUGAR & SNOW) + DRY EDIBLE + AUSTRIAN WINTER |
| PEPPERS | BELL + CHILE |
| POPCORN | SHELLED (only subtype available) |
| SORGHUM | GRAIN + SILAGE + SYRUP |
| SUGARCANE | SUGAR + SEED |
| TOMATOES | IN THE OPEN (aggregate of fresh market + processing) |
| WALNUTS | ENGLISH (only subtype available) |
